# 브리프: 모바일 셸 — 하단 탭·헤더 지표·주간 출석·복습 폴백  (base: main 4d2033c)

## 의도
폰에서 이 앱을 쓰면(사용자 둘 다 폰) 초록 상단바에 햄버거 하나뿐이다. 연속 출석·젬·XP는 데스크톱 사이드 패널에만 있어 폰에선 보이지 않고, 메뉴는 햄버거 뒤에 숨어 있다. 듀오링고가 폰에서 사람을 붙잡는 방식은 반대다 — **하단 탭이 항상 있고, 상단에 🔥연속과 💎젬이 항상 보인다.** 그 두 숫자가 눈에 계속 들어와야 "오늘도 하나만" 하게 된다. 이번 과제는 폰의 껍데기를 그 수준으로 올리는 것이다. 목표는 돈 받고 팔아도 되는 완성도라, 정렬·여백·터치 영역(최소 44px)을 아끼지 마라.

## 1. 하단 탭 바 (`components/bottom-nav.tsx`)
- 탭 5개: 학습(/learn) · 퀘스트(/quests) · 출석(/streak) · 상점(/shop) · 프로필(/profile). 리더보드는 탭에서 빼고 프로필 상단에 "순위 보기" 링크로 둔다(사용자 3명이라 탭 값어치가 낮다). 데스크톱(lg 이상)은 기존 사이드바 그대로, 하단 탭은 lg 미만에서만.
- 아이콘은 lucide-react(선명함), 활성 탭은 초록(#58cc02 계열) + 라벨 굵게. 고정 하단, `env(safe-area-inset-bottom)` 패딩, 흰 배경, 상단 2px 경계선.
- **/lesson, /practice 에선 숨긴다** — 러너는 전체 화면이고 푸터 버튼과 겹친다. 경로 판단은 클라이언트 `usePathname`.
- `app/(main)/layout.tsx`의 main에 폰용 하단 패딩을 줘서 콘텐츠가 탭에 가리지 않게.
- 햄버거(MobileSidebar)는 남긴다 — 코스 바꾸기·리더보드·로그아웃이 거기 있다.

## 2. 상단바 지표 (`components/mobile-header.tsx`)
- 왼쪽 햄버거는 그대로. 가운데/오른쪽에: 활성 코스 아이콘(탭하면 /courses) · 🔥 연속일 · 💎 젬. 숫자는 굵게, 아이콘과 붙여서. 데이터는 서버에서(`getUserProgress`, `lib/streak.getStreak`) — MobileHeader를 async 서버 컴포넌트로 바꿔도 된다. 연속이 0이면 🔥는 회색.
- 로그인 전 화면(마케팅·인증)에는 이 헤더가 없으니 신경 쓸 것 없다.

## 3. 주간 출석 달력 (`app/(main)/streak/week.tsx`)
- /streak의 두 카드 위에 이번 주(월~일, KST) 7칸. 상태 4가지: 출석 ✓(초록 채움) · 보호권으로 메운 날 ❄(하늘색) · 결석 (회색 빈 원) · 오늘 미완(초록 점선 원). 요일 라벨 아래에 원.
- 데이터: `daily_activity`에서 user의 이번 주 행(day, lessons, frozen). `lib/streak.ts`에 `weekDays(userId)` 같은 헬퍼를 추가해 페이지에서 쓴다.
- 큰 🔥 숫자는 지금보다 크게(48px 이상). "오늘 아직이에요"는 그대로.

## 4. 약점 복습 폴백 (`db/queries.getPracticeChallenges`, `app/practice/page.tsx`)
- 지금은 틀린 문항이 0개면 /practice가 /learn으로 조용히 튕긴다 — 학습 카드에 "틀린 문항이 다시 나와요"라고 써놓고 눌렀는데 아무 일도 안 일어나는 셈이다.
- 방향: 틀린 문항이 없어도 **완료한 문항 중 오래된 순으로 10개**를 뽑아 복습 세션을 만든다. 완료 문항조차 없을 때만 /learn으로 보내되, 학습 카드 문구를 그 상태에 맞게("먼저 레슨 하나를 끝내면 복습이 열려요") 바꾼다.

## 경계
- 스키마 변경 없음. 레슨 러너(app/lesson/*)는 건드리지 않는다 — 내가 동시에 고치고 있다(오답 재출제·종료 화면). 한국어 UI. 배포는 내가 한다.

## 성공 기준 (390px, 로컬 dev)
1. /learn /quests /streak /shop /profile 에 하단 탭이 보이고 현재 탭이 강조된다. /lesson 에선 없다. 콘텐츠 끝이 탭에 가리지 않는다.
2. 상단바에 🔥N · 💎N · 코스 아이콘이 보이고, 코스 아이콘을 누르면 /courses.
3. /streak 상단에 월~일 7칸, 오늘이 구분되고, 출석한 날에 ✓.
4. 틀린 문항 0·완료 문항 ≥10 계정으로 /practice → 10문항 세션이 시작된다.
5. `pnpm exec tsc --noEmit` 클린.

## 끝내는 법
main(4d2033c)에서 브랜치 `mobile-shell` → 구현 → tsc → 로컬 확인 → 커밋 → 회신: 한 일 / 파일·커밋 / 기준별 결과 / 못 한 것. 시각 판단(아이콘 선택·간격·색)은 네 것이다.
