# placement 최신식 재설계 초안 (tutor 참고용 — 미적용)

작성: ja-worker, 2026-09-03. 다정 씨 피드백 "엄청 옛날 유형"에 대응한 설계.
**오케스트레이터 결정으로 재작성은 보류** — 다정 씨가 응시 중이라 측정 보호가 우선.
tutor가 2단계 커리큘럼 작성 시 유형 참고용으로 사용. 적용 시점·방식(전체 재시드 vs
question/meta UPDATE)은 오케스트레이터와 결정.

## 근거: 60회 TOPIK II 읽기 50문항 실제 유형 (topikguide 모의고사 원형)

| 번호 | 유형 | 물음 |
|---|---|---|
| 1~2 | 빈칸 (문맥) | ( )에 들어갈 가장 알맞은 것 — 3~4급 단문 |
| 3~4 | 유의 표현 | 밑줄 친 부분과 의미가 비슷한 것 — 타기만 하면→탈 때마다 |
| 5~8 | 무엇에 대한 글인지 | 광고·안내문·주의사항 (ASSIST로 재현 중) |
| 9~12 | 내용과 같은 것 | 안내문·그래프·생활문 3~4문장 |
| 13~15 | 순서 배열 | 4문장 (ㄱ~ㄹ) → 옵션은 4가지 순서 조합 |
| 16~18 | ( ) 추론 | 4~5문장 지문의 빈칸 |
| 19~24 | 지문 쌍 | ( ) 빈칸 + 내용 일치 / 관용 표현 + 중심 생각 / 심정 + 내용 일치 |
| 25~27 | 기사 제목 설명 | 헤드라인 → 옵션은 진술문 |
| 28~31 | ( ) 추론 (5~6급) | 논증 지문 |
| 32~34 | 내용이 같은 것 (5~6급) | 과학·사회 지문 |
| 35~38 | 글의 주제 | |
| 39~41 | <보기> 삽입 위치 | ㉠㉡㉢㉣ |
| 42~43 | 소설 지문 | 심정 + 내용 일치 |
| 44~48 | 주제·( )·목적·태도 | 6급 장문 |

특징: 개별 어미 주논(느라고/는들 단독 노출)이 아니라 **지문 속 문맥 빈칸**, 유형 명칭이
머리글로 고정("다음은 무엇에 대한 글인지 고르십시오" 등). 현재 placement도 무엇에 대한
글/제목 설명/안내문은 이미 갖춰져 있고, 문제는 고급 형태론(는들·기로서니)이 단문으로
노출되는 비중 — 실전에선 이런 것들이 16~18·28~31식 긴 지문 빈칸으로 나온다.

## 재설계안 (적용 시 구조)

레슨 구조·문항 수는 기존과 동일 유지 (진단 1~5 × 12 + 진단 6 · 듣기 8 = 68) —
재시드 없이 UPDATE로도 치환 가능하도록.

- 진단 1 (3급 위주): 빈칸 4 + 무엇에 대한 글 4(ASSIST) + 내용과 같은 것 4
- 진단 2 (3~4급): 순서 배열 3 + 심정/내용 일치 쌍 2 + 기사 제목 3 + ( ) 추론 2 + 내용 일치 2
- 진단 3 (4급+): 유의 표현(관용) 4 + 중심 생각 2 + ( ) 추론 3 + 내용 일치 3
- 진단 4 (4~5급): 기사 제목 3 + 내용이 같은 것(과학·사회) 3 + 글의 주제 3 + ( ) 추론 3
- 진단 5 (5~6급): <보기> 삽입 2 + 쓴 목적 2 + 필자 태도 2 + 고급 문법 빈칸(장문 속) 3 + 장문 추론 3
- 진단 6 · 듣기: 이어질 말 2 / 장소·다음 행동 2 / 들은 내용과 같은 것 2 / 중심 생각·태도 2

급수 배분안: 3급 15 · 4급 24~25 · 5급 20~21 · 6급 8~9 (목표가 5급이므로 4·5급에 가중치,
6급은 상한 확인용). 태도·목적·심정은 tag: expression, 듣기는 listening 유지 — 집계 스키마
(level×tag) 불변.

쓰기(51~54)는 앱 밖 루틴(카톡 한 문장)으로 — 기존 설계 유지.
