# ja-jlpt 5~13주차 검토 기록 (2026-09-03, 과외 선생님)

워커(GLM) 생성분 546문항을 전수 검토했다. units/week-05~13.json을 직접 고쳤고 gen/*.py는 건드리지 않았다. 1~4주차는 손대지 않았다.

## 발견한 문제의 종류

1. **정답 오류·비문** — 예: 11-1 「くもると そうです」(비문), 7-4 なにも かいません의 정답이 '먹지 않는다', 9-1 がくせい___おもいます에 정답(だと)이 없음, 8-1 およぐ___が じょうずです에서 の도 정답, 8-3 いった(갔다)를 '온 후에'로, 11-3 수동 레슨의 절반이 존재하지 않는 형태(あまれて·かされた·おおよぎ), 11-6 てんさい≠전시회, 13-5 くださって/いただいて 둘 다 정답.
2. **독해 지문이 한국어** — 12-3, 13-3의 독해 SELECT 지문이 전부 한국어로 쓰여 있어 일본어 독해가 아니었다. 일본어(가나)로 다시 썼다.
3. **LISTEN meta.say 안에 한국어** — 지문 뒤에 「질문: …」 줄이 say에 들어 있어 TTS가 한국어를 읽게 되어 있었다(12건). 한국어 줄을 빼고 질문은 question으로 옮겼다. 대화문은 화자를 「おんなのひと：/おとこのひと：」로 적어 단일 음성이어도 JLPT 청해처럼 들린다.
4. **커리큘럼 구멍** — N5 필수(〜たい/〜ほしい, 형용사 과거, 비교, 〜なければなりません/〜なくてもいいです)와 N4 필수(보통형, 가능형, かもしれない/でしょう/はず, てみる/ておく/てしまう, 수수 표현, 의지형/つもり)가 없었다. 9-1 〜と思います가 보통형 없이, 11-4 ようになる가 가능형 없이, 12-2가 ておく/てしまう를 가르친 적 없이 나왔다. 반복·중복이던 '상황' 레슨과 10-2(4주차 중복), 13-4(12-4 중복)를 이 항목들로 교체했다.
5. **기계적 표현** — 「쓰고, 읽습니다」식 て형 연결, 「아침밥을 먹은 적이 있습니까」, 존재하지 않는 지명(ぶっかみさわ), 어휘 '루비', 번역 누락(そろそろ 돌아갈까요). 자연스러운 문장으로 바꿨다.
6. **한자 반복** — TRACE가 日本·学校·時間·先生·毎日 5개만 20회 반복. 두 번째 등장부터 人·山·川·火·水·月·木·金·土·年·今日·何로 바꿨고, 12-4를 요일·숫자·百円·日本人까지 넓혔다. 계획 밖 한자(方, 7時に会う, 30分)는 가나로.
7. **읽기(romaji) 오류** — いいですか의 で 누락, しゅうまつ→shu kyo u 등. 가나 전용 BUILD/SPEAK의 reading을 전부 재생성했다.

## 오케스트레이터가 할 일

1. `python scripts/gen_course_audio.py` 를 ja-jlpt에 다시 돌린다. say/target이 바뀐 문항은 audioSrc를 비워 두었고, 새 레슨 문항은 전부 비어 있다(정확히 100문항: 교체 레슨 전부 + say/target이 바뀐 문항). 스크립트가 텍스트 해시로 기존 클립을 재사용하므로 안 바뀐 문항은 그대로다.
2. 5~13주차만 재시드한다. 1~4주차 JSON은 git diff에 없다(1~2주차 진행 보존).
3. `gen/*.py`와 `build.py`는 이제 JSON보다 오래됐다. 실행하면 수정이 날아가므로 삭제하거나 README 한 줄로 막아 달라. curriculum.md에도 적어 두었다.
4. 5~13주차 문항 수: 60·60·60·62·61·61·61·61·60 = 546. 두 검증기(내 것, gen/common.validate) 모두 통과.
